# Assumptions and boundaries

- User confirmed Urban Air Quality Assistant; family persona selected from its brief.
- Only Indian AQI integer values 0–500 are accepted, never silently converted from US AQI or PM concentration.
- Initial New Delhi 342 is representative synthetic data, not a live observation.
- City is descriptive; no local monitors, routes, prices, forecasts or safe hours are invented.
- Household sensitivity is user-reported. No personal identifiers or diagnoses are required.
- Keyword extraction is deliberately bounded and may miss negation or complex phrasing; inspect the context form.
- Existing purifier availability is not a recommendation to buy one; no-cost source control is always possible.
- Emergency recognition is a limited deterministic safeguard, not medical triage.
- Optional AI is an explanation layer; live provider access remains unverified without credentials.
- User explicitly authorised pushing to sustik78/Saans; this does not authorise an official competition submission.
- Site is initially private under Sites policy; judges need an explicitly authorised audience change or public GitHub source.
- No certification, comprehensive penetration test or personalised safety guarantee is claimed.
